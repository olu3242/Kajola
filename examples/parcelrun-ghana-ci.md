## Section 1 — Product Requirements Document

### 1.1 Vision

West Africa's urban logistics gap costs small businesses billions in lost sales and failed deliveries. In Accra, a fashion designer on Instagram ships orders via taxi drivers who may not show up. In Abidjan, a cosmetics importer distributes via informal DHL agents with no tracking. ParcelRun fills this gap: senders book a pickup in under 2 minutes, verified couriers collect and deliver same-day, and both parties track the parcel live. Payment flows through MTN Mobile Money in Ghana and Orange Money in Côte d'Ivoire — the wallets already on every customer's phone. In three years, ParcelRun is the logistics backbone of informal West African commerce: 100,000 monthly shipments, GHS 15M+ GMV in Ghana, XOF 3B+ in Côte d'Ivoire, and the first platform that makes inter-city delivery predictable for a small trader in Kumasi or Bouaké.

### 1.3 Core User Journeys

#### Journey 1: Book a Delivery (Ghana — English)
1. Sender opens app → enters pickup address (GPS pin) and dropoff address
2. System shows fare estimate in GHS based on distance tier
3. Sender confirms → MTN Mobile Money prompt sent to sender's phone
4. Sender approves MOMO payment → job enters dispatch queue
5. Nearest available courier (PostGIS) receives push + SMS notification
6. Courier accepts → navigates to pickup → scans QR label to confirm collection
7. Parcel status moves: `booked` → `collected` → `in_transit` → `delivered`
8. Recipient confirms via SMS reply or in-app tap
9. Courier payout (net of platform fee) sent to MTN MoMo within 60 seconds

#### Journey 2: Book a Delivery (Côte d'Ivoire — French)
1. Same flow in French UI; payment via Orange Money USSD or app
2. SMS templates in fr-CI: "Votre colis est en cours de livraison. Suivi: [link]"
3. Courier payout via Orange Money B2B API

#### Journey 3: Offline Delivery Scan
1. Courier reaches a dead-zone area with no data
2. Expo app reads QR code from label locally (no network required)
3. GPS ping + scan event saved to local SQLite queue
4. On reconnect: queue flushed → parcel status updated → payout triggered

#### Journey 4: Dispute Resolution
1. Sender reports damaged or undelivered parcel within 48 hours
2. System freezes courier's next payout (idempotent escrow hold)
3. Manager reviews: parcel photos (uploaded at scan points), GPS track, timestamp chain
4. Manager resolves → release or partial refund via Mobile Money reversal

### 1.4 Non-Functional Requirements
- **Availability**: 99.5% uptime; maintenance windows Saturday 02:00–04:00 GMT
- **Offline**: Courier app caches active job details + QR scanner offline; GPS pings queued locally for 6 hours; flushed on reconnect in FIFO order
- **Latency**: Job dispatch notification < 5s; Mobile Money callback processing < 3s
- **Data efficiency**: Courier app < 3 MB initial download; maps loaded lazily per zone
- **Multilingual**: en-GH and fr-CI; all SMS templates, push notifications, and error messages in both languages; i18n JSON files per locale
- **Regulatory**: Ghana Data Protection Act 2012; Côte d'Ivoire Loi n°2013-450 sur la protection des données personnelles; ARTCI mobile money guidelines

## Section 8 — Webhook & Security Patterns

### 8.1 MTN MoMo Callback Verification

MTN MoMo (Ghana) uses Basic auth or an X-Callback-Signature header depending on tier. Production uses HMAC-SHA256:

```typescript
async function verifyMtnCallback(req: Request): Promise<boolean> {
  const sig    = req.headers.get("x-callback-signature") ?? "";
  const body   = await req.text();
  const secret = Deno.env.get("MTN_MOMO_CALLBACK_SECRET")!;

  const key = await crypto.subtle.importKey(
    "raw", new TextEncoder().encode(secret),
    { name: "HMAC", hash: "SHA-256" }, false, ["sign"]
  );
  const mac = await crypto.subtle.sign("HMAC", key, new TextEncoder().encode(body));
  const hex = Array.from(new Uint8Array(mac))
    .map(b => b.toString(16).padStart(2, "0")).join("");
  return hex === sig;
}
```

### 8.2 Orange Money Callback (Côte d'Ivoire)

Orange Money uses OAuth 2.0 Bearer token verification + HMAC body signature:

```typescript
async function verifyOrangeCallback(req: Request): Promise<boolean> {
  const sig    = req.headers.get("x-orange-signature") ?? "";
  const body   = await req.text();
  const secret = Deno.env.get("ORANGE_MONEY_CALLBACK_SECRET")!;
  // SHA-256 HMAC — same pattern as MTN above
  const key = await crypto.subtle.importKey(
    "raw", new TextEncoder().encode(secret),
    { name: "HMAC", hash: "SHA-256" }, false, ["sign"]
  );
  const mac = await crypto.subtle.sign("HMAC", key, new TextEncoder().encode(body));
  const hex = Array.from(new Uint8Array(mac))
    .map(b => b.toString(16).padStart(2, "0")).join("");
  return hex === sig;
}
```

## Section 9 — Offline & Resilience Strategy

### 9.1 Courier App Offline Mode
- Active job details cached in expo-sqlite on job assignment
- QR scanner runs fully offline (no network round-trip on scan)
- GPS pings queued locally at 30-second intervals; max 500 pings (6 hours) before oldest discarded
- Parcel scan events queued in SQLite with `offline_queued_at` timestamp
- On reconnect: `POST /offline-flush` sends full queue; server processes idempotently

### 9.2 Bilingual SMS Fallback
- All SMS templates stored as i18n JSON keyed by locale:
  ```json
  {
    "en-GH": { "parcel_collected": "Your parcel has been collected. Track: {{url}}" },
    "fr-CI": { "parcel_collected": "Votre colis a été collecté. Suivi: {{url}}" }
  }
  ```
- Sender's locale stored on `senders.locale`; selected at SMS send time
- If push notification unacknowledged in 30s → SMS fallback via Termii

### 9.3 Mobile Money Resilience
- If MTN callback not received in 120s: poll MTN QueryTransaction API (3 times, 45s apart)
- If Orange Money callback delayed: Orange provides webhook replay — no active polling needed
- Idempotency key prevents double-payments on retry
- Payout only triggers after `parcels.payment_status = 'paid'` (C2B confirmed)

### 9.4 Data Consistency Under Connectivity Loss
- Parcel status transitions are event-sourced via `parcel_scans`; current status derived from latest scan event
- Offline events older than 24 hours are accepted but flagged with `stale = true` for manager review
- Conflict: if two couriers both scan `collected` for the same parcel, the second is rejected (409) — first scan wins

## Assumptions Made

1. **MTN MoMo API access**: ParcelRun will register as an MTN Mobile Money merchant in Ghana via the Developers portal. Sandbox credentials available immediately; production API takes 2–4 weeks for approval.
2. **Orange Money API access**: Orange Money Côte d'Ivoire uses the Orange Money for Business API (OAuth 2.0). Requires local entity registration in Côte d'Ivoire for production credentials.
3. **Termii coverage**: Termii covers both Ghana and Côte d'Ivoire for SMS. Sender IDs may require per-country registration; generic numeric shortcode used as fallback.
4. **Currencies — GHS pesewa vs. XOF indivisibility**: GHS amounts stored in pesewas (integer × 100 for GHS); XOF stored as whole CFA francs (no sub-unit). Both treated as integers in DB to avoid floating-point errors.
5. **QR code labels**: MVP uses app-generated UUID string as QR content. Phase 2 migrates to printable thermal label with QR barcode per waybill.
6. **PostGIS extension**: Supabase project has PostGIS enabled for both market tenants.
7. **Multi-tenant per market**: Each country/operator is a separate tenant with its own MoMo credentials, locale, currency, and fee structure. Cross-tenant deliveries are out of scope for MVP.
8. **Data residency**: Supabase project hosted in `eu-west-1` (Frankfurt) pending Ghana DPA and ARTCI guidance on local data residency requirements. Phase 2 evaluates migration to a West Africa region.
9. **Bilingual copy ownership**: All i18n strings owned by product team; Claude generates keys and en-GH defaults; fr-CI translations reviewed by a native French speaker before launch.
10. **Offline flush conflict policy**: First scan wins. If a courier submits a `collected` event offline and a second courier's scan arrives first (online), the offline flush is rejected with 409 and flagged for manager review.
